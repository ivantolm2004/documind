# DocuMind

Интерактивный прототип AI-поиска по корпоративным документам. Интерфейс показывает практический сценарий RAG-системы: пользователь получает краткий ответ, точную цитату, файл, страницу и пункт первоисточника.

## Возможности демо

- выбор документов из базы знаний;
- готовые вопросы и свободный поисковый запрос;
- ответ с проверяемой цитатой;
- адаптивный интерфейс без внешних зависимостей.

## Коммерческая версия

Загрузка PDF/DOCX, извлечение текста, векторный поиск, OpenAI API, разграничение доступа, история запросов и журнал цитат. Стек: FastAPI, PostgreSQL/pgvector, React и Docker.

## Запуск

Откройте `index.html` в браузере.
