# DocuMind

Работающий приватный поиск по корпоративным документам. Пользователь загружает TXT/Markdown, индекс строится в браузере, а результаты содержат ранжированные фрагменты, имя файла и номер абзаца.

## Возможности демо

- загрузка собственных TXT/Markdown-файлов;
- разбиение на адресуемые абзацы и TF-IDF ранжирование;
- свободный поиск с подсветкой совпадений;
- проверяемые цитаты с файлом и номером абзаца;
- адаптивный интерфейс без внешних зависимостей.

## Проверка

```bash
npm test
```

Загрузите [`examples/contract.txt`](examples/contract.txt) в [живое демо](https://ivantolm2004.github.io/documind/) и спросите: «Какой срок оплаты?»

Схема: [ARCHITECTURE.md](ARCHITECTURE.md).
